## 📋 Detailed Discrepancy Breakdown

### D-1: `config.json` Schema
- **Draft Spec**: Defines simple theme colors and URLs.
- **Codebase**: Implements `kpiPillars` (governing header cards), data source controls (`googleSheets`, `googleDrive`, `geminiNotebooks`), and a complete `features` toggle object.

### D-2: `risks.json` Field Naming & Scoring
- **Draft Spec**: Uses generic snake_case (`inherent_likelihood`, `inherent_impact`, `is_team_google`).
- **Codebase**: Uses Commonwealth standard camelCase (`inherentLikelihood`, `inherentConsequence`, `inherentRiskScore`, `residualLikelihood`, `residualConsequence`, `riskOwner`, `treatmentOwner`, `treatmentPlan`, `causeCategory`, `bundle`, `driverTreeRef`, `sourceRegister`, `sourceLabel`).

### D-3: `issues.json` Schema & Priority Tiers
- **Draft Spec**: Uses `P0`-`P3` and `status: "Open"`.
- **Codebase**: Uses `id: "AUR-ISS-001"`, `displayId: "ISS-01"`, `priority: "Urgent" | "High"`, `severity: "Critical"`, `status: "Active" | "Closed"`, `actionPlan`, `impactCategory`, and `driverTreeRef`.

### D-4: `driver_tree.json` Hierarchy & Dynamic Badge Matching
- **Draft Spec**: Hardcodes `related_risks` arrays inside deliverables.
- **Codebase**: Organizes hierarchy into `capabilityDrops` -> `gates`. Risk and issue badges are calculated dynamically at runtime by scanning `driverTreeRef` in `risks.json` and `issues.json`.

### D-5: `snapshots.json` Root Data Structure
- **Draft Spec**: Flat JSON array `[ { "week": "W27", ... } ]`.
- **Codebase**: Object map keyed by week slug `{ "snapshots": { "w22": {...}, "w27": {...} } }`.

### D-6: AI Synthesis & Action Items JSON Schema
- **Draft Spec**: Nested structure under `synthesis.executive`.
- **Codebase**: Clean top-level snapshot fields: `synthesis: { executive, technical, governance }`, `top3: [...]`, `sleeperOutlier: {...}`, `podcastScript: [...]` matching Pydantic schemas in `scripts/gemini_generator.py`.

### D-7: `server.py` REST API Endpoints
- **Draft Spec**: Lists 4 basic endpoints.
- **Codebase**: Implements 9 endpoints including Google Drive sync checking, NotebookLM deep sync, and weekly PDF report ingestion.

### D-8: Tab 1 Top 4 KPI Banner
- **Draft Spec**: Focuses on risk and issue counts.
- **Codebase**: Displays high-level program pillars (Commercial & Budget, Milestone Gate, ATO-C Gate, Critical Escalations), with risk matrices and squeeze indices in dedicated sub-panels.

### D-9: Audio Podcast Data Format
- **Draft Spec**: Static MP3 file link.
- **Codebase**: Structured conversational script in `podcastScript` with timestamps and avatars powering both interactive transcript drawer and speech audio synthesis.
