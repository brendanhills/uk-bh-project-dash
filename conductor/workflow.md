# Development Workflow

## Methodology
- Spec-Driven Development (SDD) via Conductor tracks.
- Test-Driven Development (TDD) for core data processing routines.
- Rapid Prototype Iteration & Feedback Loop.

## Plan Review & Approval Standard
- Prior to requesting approval for any implementation plan, the agent MUST render the full, unabridged hierarchical Markdown plan (all phases, tasks, sub-tasks, and verification checkpoints) directly into the conversation stream.
- Approval prompts must NEVER be presented without the complete plan text immediately preceding them in the same turn.
